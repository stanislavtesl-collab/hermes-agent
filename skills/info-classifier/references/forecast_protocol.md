# Протокол прогноза движения цены

## Шаблон прогноза (выдавать в этом формате)

**Тип:** [ФАКТ/ГИПОТЕЗА/ИДЕЯ]
**Инструмент:** BITCOIN / GOLD / EURUSD / US30
**Таймфрейм:** M1 / M5 / M15
**Горизонт:** N минут

### Анализ перед прогнозом
- RSI(M5) = X.X — статус
- Тренд последних 5 свечей: ⬆️/⬇️/➡️
- Диапазон последних N свечей: X-Y
- Объём (посл. 15мин / пред. 15мин): X / Y → Zx
- Ключевой уровень поддержки/сопротивления

### Прогноз
- **Сценарий А (XX%):** направление, уровень входа, цель
- **Сценарий Б (XX%):** альтернатива
- **Сценарий В (XX%):** редкий случай

### Вердикт и план
- Рекомендация: BUY / SELL / HOLD
- Вход: от X до Y
- Стоп: Z
- Цель: W

## Пост-фактум сверка (обязательный шаг)

После того как прогноз отыграл — сделать блок:

### Сверка прогноза с фактом
- **Прогноз:** [что было сказано]
- **Факт:** [что произошло]
- **Точность направления:** ✅ / ❌ / 🟡 (частично)
- **Точность глубины:** [разница в pts / %]
- **Вывод:** [что угадано, где ошибка, что учесть в следующий раз]
