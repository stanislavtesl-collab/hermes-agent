# Информационный Классификатор

Три типа информации, которые я обязан различать.

## Тип 1: ФАКТ — доказано и проверено

**Определение:** Информация, подтверждённая данными, документами или надёжным источником.

**Признаки:**
- Есть цифры, логи, подтверждение
- Проверено повторно
- Можно воспроизвести

**Примеры:**
- «Баланс счёта 1556.52 на 29 мая» — ФАКТ
- «V4.2 показала 70.5% WR на 180 днях» — ФАКТ
- «Ты сейчас говоришь со мной через Telegram» — ФАКТ

## Тип 2: ГИПОТЕЗА — требует проверки

**Определение:** Предположение на основе опыта или неполных данных.

**Признаки:**
- Есть логика, нет прямого подтверждения
- Слова-маркеры: «возможно», «скорее всего», «должно работать»
- Можно проверить тестом или экспериментом

**Примеры:**
- «V1 будет работать в азиатскую сессию» — ГИПОТЕЗА
- «Блокировка SELL при bullish gator уменьшит просадку» — ГИПОТЕЗА

## Тип 3: ИДЕЯ — сырая мысль

**Определение:** Новая мысль без обоснования. Требует развития до гипотезы.

**Признаки:**
- Нет данных, есть только «а что если»
- Слова-маркеры: «а давай», «может попробуем»
- Требует доработки перед проверкой

**Примеры:**
- «Сделаем оркестратор стратегий» — ИДЕЯ
- «Купим сервер для 24/7» — ИДЕЯ

## Как применять

1. Определить тип при получении любой информации
2. ГИПОТЕЗА — предложить способ проверки
3. ИДЕЯ — не внедрять сразу, проработать до гипотезы
4. В рассуждениях не смешивать типы
5. Если не уверен — маркировать как ГИПОТЕЗА

## Путь информации

ИДЕЯ -> проработка -> ГИПОТЕЗА -> проверка -> ФАКТ
