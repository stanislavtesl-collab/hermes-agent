# Triple-Check Protocol — урок от пользователя 29.05.2026

## Правило

Перед внедрением любой стратегии/алгоритма/изменения:
1. **Первый проход** — написать код/логику
2. **Второй проход** — перечитать критически. Какие условия реально нужны? Какие — украшательства? Не дублируют ли друг друга?
3. **Третий проход** — если > 5-6 условий → урезать до 4 самых сильных. Перегруженная стратегия не работает (см. урок с Fibo + фрактал + Alligator).

## Практика

После написания монитора v2 я добавил 8 условий в V1. На третий проход оказалось:
- dist < 15pts дублирует "цена у EMA20"
- Fibo рядом почти всегда выполняется если цена у EMA20
- Фрактал требует 30 мин задержки — бесполезен для M5

**Результат:** сократил до 4 условий. Код работает так же, ошибок меньше.

## Памятка для аудита стратегий

- Условие блокирует плохие входы? → оставить
- Условие почти всегда выполняется? → убрать (шум)
- Условие требует >10 мин данных? → не для M5/M1
- Есть ли дубликат среди условий? → один оставить
