# Позиционная торговля GOLD на M15 — Концепция (1 June 2026)

## Цель

Переход от скальпинга M5 (0.03 лота, 15-30pts) к позиционной торговле на M15 (0.03→0.5 лота, 200-300pts).

## Почему это другой класс торговли

| Аспект | Скальпинг (V4.2/V5.0) | Позиционка M15 |
|:-------|:----------------------|:----------------|
| Таймфрейм | M1/M5 | M15 |
| Время удержания | 1-30 мин | 2-48 часов |
| Цель | 15-30pts | 200-300pts |
| SL | 30-100pts | 50-150pts |
| Лот | 0.03 | 0.03→0.5 |
| Кол-во сделок/день | 50-130 | 1-3 |
| Годовая цель | Нет ($6/сделка) | $100-150/сделка |

## Трендовая структура для позиционки

```
H4 ──→ глобальное направление (SMA20 vs SMA50 на H4)
  ↓
H1 ──→ тренд дня (SMA20 vs SMA50 на H1)
  ↓
M15 ──→ точка входа (откат к EMA20 + свечная структура)
```

**Правило:** Все три ТФ должны подтверждать направление. Если хотя бы один против — не входить.

## Структура входа

### Условия для BUY:
1. H4: BULLISH (SMA20 > SMA50)
2. H1: BULLISH (цена выше SMA20) ИЛИ откат к SMA50
3. M15: цена коснулась или пересекла EMA20 снизу вверх
4. M15 RSI(14) < 40 (не перекуплен)
5. Подтверждение: зелёная свеча на M15 с телом > 1/2 ATR

### Условия для SELL:
1. H4: BEARISH
2. H1: BEARISH
3. M15: цена коснулась или пересекла EMA20 сверху вниз
4. M15 RSI(14) > 60
5. Подтверждение: красная свеча на M15

## SL и TP

### SL:
- По M15 swing low/high за последние 10 свечей
- Максимум: H1 ATR × 1.5
- Минимум: 50pts (для 0.03), 30pts (для 0.5)

### TP:
- Цель 1 (partial 30%): 100pts
- Цель 2 (остаток): 200-300pts
- ИЛИ трейлинг с offset=50pts от максимума (после цели 1)

## Требования к реализации

Пока не реализовано. Нужно:
1. Отдельный монитор M15 (H4 + H1 + M15 анализ)
2. Отдельный executor для позиционки (другой magic, другой лот)
3. Отдельный сигнальный файл
4. Возможность переключения между скальпингом и позиционкой

## Когда использовать

- Есть время следить за рынком (не ночью)
- H4 + H1 тренды совпадают
- Рынок не в сильном тренде (ATR < $15)
- Пользователь хочет "серьёзной торговли" с большими целями
