# Filter Relaxation Pattern (1 June 2026)

Когда пользователь говорит «ослабь фильтры» — значит убрать тренд-фильтры и торговать пробои в обе стороны.

## Что ослаблять

| Стратегия | Исходный фильтр | Ослабленный |
|-----------|----------------|-------------|
| V4.2 (M1+H1) | H1 EMA50 тренд (UP→BUY, DOWN→SELL) | Любой пробой M1 EMA20 — BUY если вверх, SELL если вниз |
| V5.0 (M5+M15) | M15 EMA50 тренд (UP→BUY @ swing high, DOWN→SELL @ swing low) | Любой пробой swing high/low — BUY при пробое high, SELL при пробое low |

## Когда применять

- Рынок в **SIDEWAYS** на обоих ТФ (H1 и M15)
- Нет явного тренда, но цена движется (5-15pt колебания)
- Пользователь говорит «пробуем», «ослабь», «убери фильтры»

## Как вернуть фильтры

Когда рынок выйдет из боковика — пользователь скажет. Или если PnL начинает падать.

## Implementation

**V4.2:** Убрать `if trend in ("UP", "DOWN"):` из main-цикла и убрать проверку `trend == "DOWN" / trend == "UP"` внутри `check_m1_signal()`. Оставить только `prev_c > prev_e20 and last_c <= last_e20 → SELL` и `prev_c < prev_e20 and last_c >= last_e20 → BUY`.

**V5.0:** Убрать проверку `trend == "UP" / "DOWN"` перед сигналами. Убрать блокировку `if trend == "SIDEWAYS": return None`. Оставить только проверку `nearest_high / nearest_low` + пробой.
