# Averaging Rules — 1 June 2026 (обновлено 14:50)

## Ключевое уточнение от пользователя: "в режиме онлайн-времени ищешь самую выгодную точку для усреднения."

**Не усреднять сразу при 30pts — ждать касания сильного уровня.** Executor проверяет каждые 2с, но усредняет ТОЛЬКО когда цена на уровне.

## Актуальная механика (executor v3, обновлён)

Функция `try_average(pos, positions_list, magic, h1_trend)` вызывается **в каждом цикле** после `manage_trail()`.

### Условия срабатывания (ВСЕ должны быть TRUE):

1. `trail["averaged"]` не установлен
2. `pos.ticket == trail["ticket"]`
3. Убыток > 20pts (выход из зоны шума, смягчено с 30)
4. H1 тренд подтверждает: BUY при BULLISH/SIDEWAYS, SELL при BEARISH/SIDEWAYS
5. **Цена на сильном уровне** (ПРОВЕРЯЕТСЯ В ТАКОМ ПОРЯДКЕ):

   **а) Круглый уровень** — приоритет:
   - `current - int(current) < 0.15` (цена $XXXX.00-XXXX.15)
   - `current - int(current) > 0.85` (цена $XXXX.85-XXXX.99)
   - `abs(cents - 0.50) < 0.15` (цена $XXXX.35-XXXX.65)

   **б) H1 swing low/high** — если круглого уровня нет:
   - Для BUY: `0 <= current - h1_swing_low < 1.50` (цена в $1.50 от H1 поддержки)
   - Для SELL: `0 <= h1_swing_high - current < 1.50` (цена в $1.50 от H1 сопротивления)

   **в) M15 swing low/high** — если H1 уровня нет:
   - Для BUY: `0 <= current - m15_swing_low < 1.00`
   - Для SELL: `0 <= m15_swing_high - current < 1.00`

6. Если ни один уровень не совпал — `return False`, ждём следующего цикла

### Пример правильной работы:
```
BUY 0.03 @ $4,470 → цена падает
  t=0:  loss=10pts  → skip (loss < 20)
  t=2s: loss=22pts  → skip (не на уровне, цена $4,448)
  t=4s: loss=28pts  → skip (не на уровне, цена $4,442)
  t=6s: loss=34pts  → цена $4,435.00! Круглый уровень! → УСРЕДНЯЕМ
  Средняя: ($4,470 + $4,435) / 2 = $4,452.50
  SL на обе: $4,460.50 (avg + $8.00)
```

### Неправильно (как было до уточнения):
```
BUY 0.03 @ $4,470 → цена падает
  t=0:  loss=32pts → цена $4,438, НЕ круглый уровень, НО loss>30 → усредняем
  → ВХОД по плохой цене, средняя хуже
```

### После усреднения:
- `trail["averaged"] = True`
- `trail["entry_price"] = new_entry` (средневзвешенная)
- SL на обе позиции от `new_entry ± SL_DISTANCE`
- Трейлинг в `manage_trail()` использует `trail["entry_price"]`
